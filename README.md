# wrapatom

Wrap and reshape atom text streams with deterministic transforms.

**Site:** https://theworker02.github.io/wrapatom/

## Install / run

```bash
git clone https://github.com/theworker02/wrapatom.git
cd wrapatom
node src/cli.js
node --test
```
